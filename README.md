# Bok! – Kroatisch lernen

Eine App für **iPhone und Desktop**, mit der man als Deutschsprachige:r Kroatisch (und damit auch Serbisch und Bosnisch) lernt:
Wortschatz, Grammatik und Hörtraining – aufgebaut nach dem, was die Lernforschung am besten belegt hat.

Die App ist eine installierbare Web-App: Sie läuft im Browser, lässt sich auf dem iPhone zum Home-Bildschirm und am
Computer als eigenes Programm hinzufügen und funktioniert danach auch ohne Internet. Es gibt kein Konto, keinen Server
und keine Werbung; der Lernstand bleibt auf dem Gerät.

## Was drin ist

| Bereich | Inhalt |
|---|---|
| **Wortschatz** | 579 Wörter und Wendungen in 19 Lektionen (Niveau A1–A2), jedes mit Beispielsatz, Ton, Genus und – wo sie abweicht – der serbischen Form |
| **Grammatik** | 22 Themen mit kurzer Erklärung, Tabellen, antippbaren Beispielen und 298 Aufgaben: alle sieben Fälle, Präsens, Perfekt, Futur, Aspekt, Modalverben, Imperativ, Wortstellung, Steigerung |
| **Audio** | Ton zu jedem Wort und Satz (auch verlangsamt), Hörverstehen, Diktate, 18 Dialoge zum Hören, Mitlesen und Nachsprechen mit Aufnahme der eigenen Stimme, freihändiger Audio-Trainer |
| **Wiederholung** | Zeitplan nach FSRS: Jede Karte wird fällig, kurz bevor man sie vergessen würde |
| **Drumherum** | Tagesziel und Serie, Statistik, Wörterbuch, helles und dunkles Design, kyrillische Schreibweise zum Einblenden, Sicherung des Lernstands als Datei |

Gelehrt wird die kroatische Standardsprache in lateinischer Schrift. Ein eigenes Kapitel erklärt die Unterschiede zum
Serbischen und Bosnischen und die kyrillische Schrift.

## Installieren

Die App braucht nur einen Ort, an dem ihre Dateien über HTTPS erreichbar sind – zum Beispiel GitHub Pages:

1. Im Repository **Settings → Pages** öffnen.
2. Unter *Build and deployment* als Quelle **Deploy from a branch** wählen, den Branch mit der App und den Ordner **/ (root)** einstellen, speichern.
3. Nach etwa einer Minute ist die App unter `https://<benutzername>.github.io/Deutsch-Kroatisch/` erreichbar.

Danach auf dem jeweiligen Gerät:

- **iPhone / iPad:** Adresse in Safari öffnen → Teilen-Symbol → **Zum Home-Bildschirm**.
- **Windows / Linux (Chrome, Edge):** Installations-Symbol rechts in der Adressleiste oder Menü → **App installieren**.
- **Mac (Safari):** Ablage → **Zum Dock hinzufügen**.
- **Android:** Menü → **App installieren**.

### Ton

Die App spricht mit den Stimmen des Geräts. iPhone, iPad, Mac und Android bringen eine kroatische Stimme mit;
unter Windows ist **Microsoft Edge** die einfachste Wahl, weil Edge kroatische Stimmen eingebaut hat. Fehlt eine Stimme,
erklärt die App unter *Mehr → Einstellungen → Audio*, wie man sie einrichtet – alle Aufgaben außer den reinen Höraufgaben
funktionieren auch ohne Ton.

### Lernstand zwischen iPhone und Computer übertragen

Unter *Mehr → Einstellungen → Lernstand sichern und übertragen* lässt sich eine Sicherungsdatei erstellen und auf dem
anderen Gerät einspielen. Einen automatischen Abgleich gibt es nicht, weil die App bewusst ohne Server auskommt.

## Wie die App das Lernen aufbaut

Vor dem Bau stand die Frage, wie Erwachsene eine Sprache am wirksamsten lernen. Zehn Ergebnisse aus der Forschung
bestimmen den Aufbau:

| Erkenntnis | Umsetzung in der App |
|---|---|
| **Abrufen schlägt Wiederlesen.** Sich selbst abzufragen und verteilt zu üben sind die beiden einzigen von zehn untersuchten Lerntechniken mit der Bestnote (Dunlosky u. a., 2013). | Jede Aufgabe verlangt eine Antwort, bevor die Lösung erscheint. |
| **Verteilt wiederholen.** Wachsende Abstände bringen beim Sprachenlernen einen kleinen bis mittleren, vor allem langfristigen Vorteil (Meta-Analyse von Kim & Webb, 2022, 48 Experimente). | Zeitplan nach FSRS-6; Fehler kommen noch in derselben Sitzung wieder. |
| **Erst erkennen, dann produzieren.** Beides sind verschiedene Fähigkeiten; Karteikarten-Training ist dabei besonders effizient (Webb u. a., 2020). | Neue Wörter starten als Auswahlaufgabe; je fester ein Wort sitzt, desto öfter wird geschrieben oder nach Gehör notiert. |
| **Vier Stränge im Gleichgewicht** (Nation, 2007): verständlicher Input, eigener Output, gezieltes Lernen, Geläufigkeit. | Dialoge · Schreib- und Sprechaufgaben · Wortschatz und Grammatik · Wiederholung und Audio-Trainer. |
| **Regeln ausdrücklich erklären.** Erwachsene lernen Grammatik mit benannten Regeln plus Übung schneller als nur aus Beispielen (Norris & Ortega, 2000; Goo u. a., 2015). | Jedes Thema: kurze Erklärung, Tabelle, Beispiele, sofort Aufgaben. |
| **Themen mischen.** Abwechselndes Üben führte bei Grammatik oft zu besserem Behalten (Nakata & Suzuki, 2019; Pan u. a., 2019) – die Befunde sind nicht einheitlich. | Wiederholungen mischen Wörter und Grammatik aller Lektionen; im Kurs wechseln sich beide ab. |
| **Häufige Wörter zuerst.** Ein kleiner Kern trägt den Großteil jeder Unterhaltung (für das Englische: rund 2000 Wortfamilien für etwa 80–90 % üblicher Texte). | Der Kurs beginnt mit dem Alltagskern. |
| **Hören und Nachsprechen.** Shadowing verbessert das Hörverstehen (Hamada, 2016); für die Aussprache ist die Studienlage dünner, aber ermutigend. | Ton überall, Dialoge Satz für Satz nachsprechen, aufnehmen, vergleichen. |
| **Wörter im Zusammenhang.** Ein Wort zu kennen umfasst Klang, Schreibung, Formen und typische Verbindungen. | Jedes Wort hat einen Beispielsatz, der als Diktat und Satzbau-Aufgabe wiederkehrt. |
| **Kurz, aber täglich.** Folgt direkt aus dem Vorteil des verteilten Übens. | Kleines Tagesziel, Serie, Einheiten von wenigen Minuten. |

Dieselbe Übersicht mit Quellenangaben steht in der App unter *Mehr → Lernmethode*.

### Ablauf einer Lerneinheit

1. **Vorstellen:** Wort, Ton, Bedeutung, Beispielsatz.
2. **Wiedererkennen:** sofort eine Auswahlaufgabe, nach jedem zweiten Wort ein Rückblick nur über das Ohr.
3. **Abrufen:** vom Deutschen zum Kroatischen, in gemischter Reihenfolge.
4. **Schreiben und Bauen:** das Wort tippen, Beispielsätze zusammensetzen.

Wer keinen Fehler macht, sieht das Wort nach zwei Tagen wieder; danach wachsen die Abstände auf Wochen und Monate.

## Entwicklung

Die App besteht aus HTML, CSS und JavaScript-Modulen ohne Abhängigkeiten und ohne Build-Schritt.

```bash
npm start      # lokal ausprobieren: http://localhost:8080
npm test       # Tests für Wiederholungsplanung, Antwortprüfung und Lerninhalte
npm run e2e    # Durchlauf im Browser mit Bildschirmfotos (benötigt Playwright)
npm run icons  # App-Symbole neu erzeugen (benötigt Playwright)
```

| Pfad | Aufgabe |
|---|---|
| `js/data/` | Lerninhalte: `vocab.js`, `grammar.js`, `dialogues.js` – hier wird ergänzt und korrigiert |
| `js/content.js` | bereitet die Inhalte auf und baut daraus Aufgaben |
| `js/session.js` | Ablauf einer Lernsitzung mit Rückmeldung und Bewertung |
| `js/srs.js` | Wiederholungsplanung (FSRS-6, gegen die Referenz-Implementierung `ts-fsrs` geprüft) |
| `js/learning.js` | Kursfortschritt, nächster Schritt, Zusammenstellung der Sitzungen |
| `js/speech.js` | Sprachausgabe und Aufnahme |
| `js/store.js` | Lernstand und Einstellungen (localStorage) |
| `js/views/` | die einzelnen Seiten |
| `sw.js` | Offline-Betrieb; bei neuen Dateien die Liste ergänzen und `VERSION` erhöhen |

### Inhalte erweitern

Ein Wort ist eine Zeile in `js/data/vocab.js`:

```js
['kava', 'Kaffee', 'Pijem kavu s mlijekom.', 'Ich trinke Kaffee mit Milch.', { g: 'f', sr: 'kafa' }],
```

Eine Grammatikaufgabe ist eine Zeile in `js/data/grammar.js`:

```js
c('Pijem ___. (kava)', 'kavu', 'Ich trinke Kaffee.', ['kava', 'kave', 'kavom']),
```

`npm test` prüft danach, ob alles vollständig und eindeutig ist.

## Grenzen

- Die Sprachausgabe stammt vom Gerät; Klang und Verfügbarkeit hängen von Betriebssystem und Browser ab.
- Der Audio-Trainer läuft nur bei eingeschaltetem Bildschirm (die App hält ihn dafür wach).
- Die Lerninhalte wurden sorgfältig erstellt, aber nicht von Muttersprachler:innen lektoriert.
- Die App ersetzt keine echten Gespräche – sie legt das Fundament dafür.
